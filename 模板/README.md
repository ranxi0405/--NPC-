# 通用 NPC 模板

## 用途

复制本目录，改掉身份字段，就是一个新 NPC。

战斗数据（技能/装备/灵根/悟道）已填充默认值，开箱即用。

## 使用步骤（不用命令行）

### 1. 复制
- 用文件管理器把 `模板/` 复制一份，重命名为新 NPC 名（如 `青影`）

### 2. VSCode 全局替换
- VSCode 打开新目录
- `Ctrl+Shift+H` 打开全局替换
- 按下面清单，逐个"全部替换"：

| 查找 | 替换为 | 说明 |
|---|---|---|
| `4300` | 你的模板ID（如 4202） | NPC主ID，会同时改掉称号ID |
| `8300` | 你的流派ID（如 8202） | 流派/等级池类型 |
| `43001` | 你的等级模板起始ID（如 42201） | 影响 43001–43015 共 15 个 |
| `9994300` | 你的信物ID（如 9994202） | 物品ID |
| `模板NPC` | 你的NPC名（如 青影） | 出现在对话、称号、信物名 |
| `模板称号` | 你的NPC称号（如 玄衣客） | NPC头顶显示 |

### 3. 部署到游戏
- 目标路径：`本地Mod测试/你的NPC名/plugins/Next/mod你的NPC名/`
- 目录结构：
mod你的NPC名/
├── Config/modConfig.json
├── Data/
└── NData/

text

### 4. 打开 enable
- 启动游戏一次（让 Next 扫到新 mod）
- 退出，用 VSCode 打开 `nextModSetting.json`
- 搜 NPC 名，找到 `"enable": false` 改成 `true`
- 保存，再启动游戏

### 5. 验证
- 推进游戏时间一会儿
- 背包里应出现「XXX信物」
- 使用信物 → NPC 出现并跟随
- 再用 → 离开

## ID 分配参考

| 用途 | 玄影 | 素影 | 模板 | 下一个可用段 |
|---|---|---|---|---|
| NPC 主 ID | 4200 | 4201 | 4300 | 4202–4299、4301 起 |
| 流派 ID | 8200 | 8201 | 8300 | 8202–8299、8301 起 |
| 等级模板 | 42001–42015 | 42101–42115 | 43001–43015 | 42201 起 |
| 信物 ID | 9994200 | 9994201 | 9994300 | 9994202 起 |

**避开幽荧 mod 占用段**：4000–4300、8000–8300、12000–12095、999900–999983。

## 进阶：让 NPC 战斗风格不同

默认战斗数据是通用的（复用本体技能 626–630 + 装备 999956–999958 + 极阴灵根）。要改：

| 想改什么 | 改哪个文件 | 字段 |
|---|---|---|
| 境界等级 | `NPCImportantDate.json` | `level`（1–15） |
| 气血上限 | `AvatarJsonData.json` | `HP` |
| 资质/悟性/神识 | 同上 | `ziZhi` / `wuXin` / `shengShi` |
| 灵根 | 同上 | `LingGen`（五行数组） |
| 技能表 | 同上 | `skills`（本体技能 ID） |
| 静态技能 | 同上 | `staticSkills` |
| 武器/衣服/戒指 | 同上 | `equipWeapon` / `equipClothing` / `equipRing` |
| 悟道流派 | 同上 | `wuDaoType` |

**注意**：所有 ID 必须是游戏本体或已装 mod 里存在的。

## 依赖
